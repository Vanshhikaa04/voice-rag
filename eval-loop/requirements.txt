# This suite imports and runs the target RAG project's real code in-process
# (see eval/target.py), so it needs that project's exact dependencies --
# there's no separate, smaller dependency set for "just the eval logic".
#
# Recommended: don't create a new venv for this repo at all. Run with the
# target project's own virtualenv Python, e.g. on Windows:
#   RAG\.venv\Scripts\python.exe -m eval.runner
# It already has everything below (plus torch+transformers if
# GENERATION_BACKEND="local" -- see the target project's own
# requirements.txt / requirements-training.txt for that GPU-specific pin).
#
# This file exists for anyone who wants a standalone venv instead. Lower
# bounds, not exact pins -- exact pins from the original dev machine (one
# specific Python version + platform) failed to resolve at all on a
# different Python version (pip couldn't find that exact faiss-cpu build,
# only later ones) the first time someone else actually tried installing
# this. A public, broadly-installed tool needs ranges; exact pins are the
# right call for the RAG project's own reproducible-training-environment
# use case, not for this one.

sentence-transformers>=3.3.1
numpy>=1.26.4
